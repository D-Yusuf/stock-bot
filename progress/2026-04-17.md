## Bugs Encountered & Fixed

### 1. Trimming loop — bot selling positions every cycle (CRITICAL)
**Problem:** When settled cash was low (~$256), `investable` (free budget) = $0.
With `investable=$0`, `target_value = 0`, so `target_qty = 0` for every ticker.
`delta_qty = 0 - session_qty` came out negative, triggering a TRIM sell every cycle.
This caused TSM to be sold at a loss 5 min after buying, and NVDA/GOOGL to be trimmed repeatedly.
**Fix:** When `investable <= 0`, set `target_qty = session_qty` so delta is always 0 — bot holds all positions and only manages SL/TP, never trims.

### 2. AAPL TP rejected — Error 201 "short position in cash account"
**Problem:** Bot was placing a standalone SELL LMT order for AAPL TP without pairing it with the existing SL via OCA group. IBKR treated it as a potential short sell and rejected it.
**Fix:** TP order is now re-placed together with SL in an OCA group so IBKR knows both orders are closing an existing long position, not opening a short.

### 3. Bot files in iCloud-synced Desktop folder
**Problem:** All bot files were under ~/Desktop/Apps/stock-bot which is synced to iCloud. iCloud set immutable flags on files, making them unreadable/uneditable by Claude Code and terminal.
**Fix:** Moved all files to ~/stock-bot (outside iCloud). Updated launchd plist paths accordingly.
